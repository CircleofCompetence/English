# 하준이의 영어게임

초등학교 1학년을 위한 모바일 영어 그림 퀴즈입니다. 100개의 기초 단어 중 매 게임마다 10문제가 무작위로 출제됩니다.

## 주요 기능

- 영어 단어 발음을 3초 간격으로 3번 재생
- 4개의 그림 보기와 정답/오답 설명
- 잔잔한 자체 생성 BGM과 정답·오답 효과음
- 매 게임 무작위 10문제, 최고 기록 저장
- 휴대폰·태블릿·PC 반응형 UI
- 별도 서버와 패키지 설치 없이 실행

## 실행하기

`index.html`을 브라우저에서 열면 됩니다. 음성은 브라우저의 영어 TTS(Web Speech API)를 사용하므로 기기마다 목소리가 조금 다를 수 있습니다.

로컬 서버를 쓰려면 Python이 설치된 환경에서 다음 명령을 실행하세요.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`으로 접속합니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**, `main`, `/ (root)`를 선택하고 저장합니다.

## 파일 구조

```text
├─ index.html       # 화면 구조
├─ styles.css       # 모바일 반응형 디자인
├─ questions.js     # 100개 단어 데이터
├─ app.js           # 게임·음성·오디오 로직
└─ assets/          # 일러스트와 파비콘
```

외부 서버로 개인정보를 보내지 않으며, 최고 점수만 브라우저의 `localStorage`에 저장합니다.
